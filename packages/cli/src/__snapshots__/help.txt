### imstudium 
Usage: imstudium [options] [command]

ImStudium — extract, sync, and plan your studies

Options:
  -V, --version                                  output the version number
  --json                                         JSON output for agents (one document on stdout;
                                                 errors as JSON on stderr)
  --quiet                                        Minimal output
  --instance <url>                               Stud.IP instance origin (default:
                                                 digicampus.uni-augsburg.de)
  -h, --help                                     display help for command

Commands:
  onboard [options]                              First-time setup: login, sync workspace, wire
                                                 agents (idempotent)
  init [options]                                 Login + sync Studium workspace (use onboard for
                                                 first-time agent setup)
  login [options]                                Sign in via browser — opens Stud.IP login every
                                                 time
  logout                                         Clear stored session
  status                                         Auth and instance status
  context [options]                              Your study briefing in one call — semester, today,
                                                 Abgaben, Klausuren, new files, news
  today [options]                                Today's dates across all current courses (cancelled
                                                 ones marked)
  week [options]                                 This week's dates, grouped by day (Mo–So)
  stundenplan [options]                          Your regular weekly plan (cycles), single dates and
                                                 cancellations
  holidays [options]                             Public holidays and the lecture period (no lectures
                                                 on Feiertage)
  tasks [options] [course]                       Courseware tasks (Aufgaben) with deadlines, soonest
                                                 first
  klausuren [options]                            Exam timeline (klausuren.md; --json from
                                                 studium.json)
  changes [options]                              What arrived from Stud.IP recently (new and updated
                                                 files)
  news [options] [course]                        Announcements: one course, or all current courses
                                                 merged newest-first
  inbox [options]                                Your Stud.IP messages, newest first (reading never
                                                 marks them read)
  outbox [options]                               Messages you sent, newest first
  message <id>                                   One message in full, with sender and recipients
                                                 (does not mark it read)
  forum [options] [course]                       Course forum: discussions newest activity first,
                                                 one thread, or --save as markdown
  blubber [options] [course]                     Blubber chats: a course's threads with latest
                                                 comments, or your stream
  feed [options]                                 What happened in your courses: Stud.IP's activity
                                                 stream, newest first
  search [options] <query...>                    Ranked search across slides, scripts, news, forum,
                                                 courseware and wiki — offline
  courseware|cw [options] [course]               Courseware (Lernmaterial): units, page outline;
                                                 --save writes markdown + files
  wiki [options] [course] [page]                 Course wiki: page tree, one page as markdown, or
                                                 --save into the workspace
  files                                          Course files: folder tree and single downloads
  courses                                        Your enrolled courses (live from Stud.IP)
  studium [options]                              Show STUDIUM.md (human) or studium.json (--json)
  people [options] [course]                      Who teaches what: lecturers, tutors, groups and
                                                 student count per course
  sprechstunden|consultations [options] [query]  Upcoming office hours (Sprechstunden) of your
                                                 lecturers — read-only, booking stays in Stud.IP
  catalog                                        Course catalog for semester planning
                                                 (Vorlesungsverzeichnis)
  arbeit [options]                               Written work (Hausarbeit, Seminar-, Bachelor-,
                                                 Masterarbeit): registry, style, Formvorgaben,
                                                 checks
  quellen [options]                              The Arbeit's citation registry: add by
                                                 DOI/ISBN/URL, import from Zotero or Citavi, check,
                                                 export
  zitieren [options] <cites...>                  A citation in the Arbeit's style: in the text, or
                                                 the footnote for note styles
  literatur [options]                            The bibliography (Literaturverzeichnis) in the
                                                 Arbeit's style
  stile [options]                                Citation styles (CSL): the bundled set, yours, and
                                                 any of the ~10,000 in the CSL repository
  semester [options]                             Where you are in the semester; start a new one
                                                 (archive the last, sync the new)
  sync [options]                                 Sync files and rebuild the Studium workspace
                                                 (current semester by default)
  extract|ingest [options]                       Local ingest: pdf-inspector (PDF) + AnyDoc (Office)
                                                 → content.md; photos copied to pages/
  index [options]                                Build/rebuild page index (corpus.jsonl) — for agent
                                                 grep / semantic search, not a custom search engine
  view [options]                                 Build viewer.html for slide PNGs — fast path for
                                                 Playwright / browser agents
  watch [options]                                Continuous sync loop (--json: one JSON line per
                                                 round)
  export                                         Export Stud.IP data as files (calendar.ics)
  routes [options] [query]                       Every JSON:API route this Stud.IP offers (cached
                                                 from /discovery)
  api [options] <path>                           Call any Stud.IP JSON:API route — the escape hatch
                                                 for agents
  schema [command...]                            JSON Schema of a command's --json output (from
                                                 @imstudium/contract)
  setup                                          Idempotent agent wiring (skills, MCP) — only
                                                 updates what changed
  config                                         Show or change ~/.config/imstudium/config.json
  session                                        Session management: import a Stud.IP session cookie
  doctor [options]                               Check install, session, workspace, ingest engines,
                                                 agent setup and the MCP door — each with a fix
  update                                         Upgrade CLI (if needed) and refresh agent
                                                 skills/MCP
  module [options]                               Harness modules for mina — course/exam counts, no
                                                 student id
  semesters                                      List Stud.IP semesters and show the
                                                 calendar-current one (see also: semester)
  discover                                       List JSON:API routes (see also: routes)
  help [command]                                 display help for command

### imstudium onboard
Usage: imstudium onboard [options]

First-time setup: login, sync workspace, wire agents (idempotent)

Options:
  -o, --output <dir>  Workspace directory (default: "~/Studium")
  -y, --yes           Non-interactive
  --agents-only       Skip login/sync — only configure Cursor, Claude Code, Claude Desktop, Codex,
                      Windsurf, OpenCode
  --skip-sync         Login + agent setup, no file sync
  --force             Re-install skills/MCP even when unchanged
  --all-agents        Configure every harness path, not only detected ones
  -h, --help          display help for command

### imstudium init
Usage: imstudium init [options]

Login + sync Studium workspace (use onboard for first-time agent setup)

Options:
  -o, --output <dir>  Workspace directory (default: ~/Studium or IMSTUDIUM_WORKSPACE)
  -y, --yes           Non-interactive (skip prompts)
  --relogin           Sign in again even if a session is already stored
  --chrome-profile    Use your Chrome profile with saved passwords (quit Chrome first)
  --extract           Extract new/changed files to markdown and rebuild the search index
  -h, --help          display help for command

### imstudium arbeit new
Usage: imstudium arbeit new|neu [options] <title...>

Start an Arbeit: its folder, an empty citation registry, quellen.bib and ARBEIT.md

Arguments:
  title                 Working title

Options:
  --typ <typ>           hausarbeit, seminararbeit, bachelorarbeit, masterarbeit, projektarbeit,
                        essay, protokoll, referat, dissertation, sonstige (default hausarbeit)
  --stil <id>           Citation style: a bundled id (imstudium stile), a .csl file, or one you add
                        later with stile add (default from --preset)
  --preset <name>       Formvorgaben to start from: standard, apa7, geisteswissenschaft, juristisch,
                        technik (default standard)
  --course <name>       The course it is written for (title fragment, shortcut or slug)
  --abgabe <date>       Deadline, 2027-03-15 or 15.03.2027
  --umfang <length>     Required length: 15s (Seiten), 6000w (Wörter) or 40000z (Zeichen)
  --toleranz <percent>  Allowed deviation from --umfang in percent (default 10)
  --sprache <lang>      Language of the work, e.g. de-DE or en-US (default: the style's, else de-DE)
  --betreuung <name>    Supervisor (stays in your workspace)
  --slug <slug>         Folder name under arbeiten/ (default from the title)
  --dir <folder>        Create the Arbeit in this folder instead (e.g. your LaTeX or Typst project)
  -o, --output <dir>    Workspace directory (default: ~/Studium or IMSTUDIUM_WORKSPACE)
  -h, --help            display help for command
