# Bundled CSL styles and locales

These files are copied unchanged from the Citation Style Language project, a curated set of the styles German faculties ask for most:

- `styles/`: from [citation-style-language/styles](https://github.com/citation-style-language/styles)
- `locales/`: from [citation-style-language/locales](https://github.com/citation-style-language/locales)

Both are licensed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Each style names its authors and contributors in its `<info>` block.

To update a style, copy the new file from the repository. Don't edit one here: a change belongs upstream. `imstudium stile add <id>` fetches any other style into an Arbeit's `stil/` folder.
